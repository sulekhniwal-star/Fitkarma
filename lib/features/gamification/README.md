# Gamification Feature (`lib/features/gamification/`)

## Purpose
Manages Karma Hub, achievement badge grids, level-up animations, outcome-based XP rewards, and demographic cohort benchmark comparisons.

## Subdirectories
- **`models/`**: `Achievement` and `CohortBenchmark` data models.
- **`providers/`**: Riverpod state management for XP points, user levels, and unlocked badges.
- **`screens/`**: Interactive `KarmaHubScreen` with achievement grid and cohort benchmarks.
