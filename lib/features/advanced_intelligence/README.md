# Advanced Intelligence Feature (`lib/features/advanced_intelligence/`)

## Purpose
Manages Phase 15 Advanced Intelligence features: Adaptive Metabolism Engine (TDEE tracking based on weight trends), Environmental Health Layer (AQI/UV/Humidity), Women's Advanced Health Layer (Cycle phases), and Longevity Score Engine.

## Subdirectories
- **`models/`**: Data models for Environmental Health, Menstrual Cycle, and Adaptive TDEE.
- **`providers/`**: Riverpod state management for Longevity Score and AQI alerts.
- **`screens/`**: Interactive `AdvancedIntelligenceScreen` displaying adaptive TDEE, AQI warnings, and cycle phases.
