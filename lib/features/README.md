# Features Module (`lib/features/`)

## Purpose
The `features` directory houses domain-specific UI components, screen controllers, state providers, and business workflows.

## Subdirectories
- **`onboarding/`**: Multi-step onboarding, profile setup, metabolic baseline calculation, and permission flows.
- **`daily_mission/`**: Daily Briefing dashboard, readiness score display, recovery prescriptions, and core daily actions.
- **`coach/`**: AI adaptive coaching UI, multi-model chat interaction, and prompt/response presentation.
- **`nutrition/`**: Indian food database logger, barcode reader integration, micronutrient trackers, and periodization indicators.
- **`workout/`**: Workout tracker, set/rep logging, progressive overload calculations, and MediaPipe pose feedback views.
