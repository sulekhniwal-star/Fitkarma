# Festivals Feature (`lib/features/festivals/`)

## Purpose
Manages cross-module adaptation for all 10 Indian cultural festivals, 3-day Survival Mode pre-activations, Navratri Fasting Filters, and Ramadan Sehri/Iftar nutrition modes.

## Subdirectories
- **`models/`**: `FestivalEvent` and `FastingFilter` data models.
- **`providers/`**: Riverpod state management for festival calendars and active survival modes.
- **`screens/`**: Interactive `FestivalDashboardScreen` for festival customization and fasting modes.
