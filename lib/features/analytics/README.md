# Analytics Feature (`lib/features/analytics/`)

## Purpose
Manages Lean Body Mass (LBM) estimation, Fat Mass calculations, 90-day trajectory range bands, and body circumference logging.

## Subdirectories
- **`models/`**: `BodyMeasurementLog` and `LeanMassResult` data models.
- **`providers/`**: Riverpod state management for body measurements and lean mass trends.
- **`screens/`**: Interactive `VisualAnalyticsScreen` with trajectory range charts.
