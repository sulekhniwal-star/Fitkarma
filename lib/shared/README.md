# Shared Module (`lib/shared/`)

## Purpose
The `shared` directory contains reusable design system tokens, typography, theme definitions, and core UI widgets utilized across multiple features.

## Subdirectories
- **`theme/`**: Design system tokens including `app_colors.dart`, `app_typography.dart`, and `app_spacing.dart`.
- **`widgets/`**: Reusable component widgets like tier-aware `GlassCard`, `GlowingMetric`, `ActivityRings`, `QuickLogFab`, and `HealthScoreRing`.
